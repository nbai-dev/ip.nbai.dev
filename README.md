# NBAI · IP 与网络分流诊断

一个纯前端、浏览器本地运行的网络诊断工具，用于快速检查当前网络环境的出口 IP、分流状态、站点连通性、WebRTC 泄露风险和终端环境信息。

在线地址：https://ip.nbai.dev

## 项目简介

NBAI 是一个面向网络观测与排障场景的轻量工具。它不需要登录、不依赖后端、不上传检测数据，所有核心逻辑都在浏览器中本地执行。

你可以用它来：

- 检测当前网络的 IPv4 / IPv6 出口
- 对比国内与海外分流链路的实际表现
- 观察常用站点的连接速度和可用性
- 检查 WebRTC 是否泄露公网或局域网地址
- 识别 Anycast / Cloudflare 边缘节点命中情况
- 进行自定义域名测速与简短排障记录

## 主要功能

### 1. 多源 IP 出口检测

- 6 路独立出口通道并发检测
- 区分国内直连、国内 BGP、Cloudflare Anycast 和海外分流出口
- 支持隐私模式，隐藏部分 IP 信息，适合截图和分享

### 2. 国内外站点连通性与延迟

- 覆盖国内热门站点与国际 / AI 平台
- 可查看网站是否可达，以及响应延迟概览
- 支持按“全部 / 已连通 / 需排查”筛选
- 提供站点重测与技术详情切换

### 3. WebRTC 与环境诊断

- 检查公网反射地址（srflx）和本地候选地址
- 评估 WebRTC 是否存在泄露风险
- 展示浏览器、平台、UA、语言等终端环境信息

### 4. 自定义测速

- 支持输入任意域名或 URL 进行即时测试
- 适合快速验证某个站点是否可访问

### 5. 诊断报告

- 生成简洁文本、Markdown 或 AI 排障格式的诊断摘要
- 可一键复制、保存截图、分享到社交平台

## 设计原则

- 纯前端实现：整个页面由 HTML、CSS、JavaScript 组成
- 本地执行：检测请求在用户浏览器中发起
- 无登录要求：不绑定账号，不依赖后端服务
- 面向实用：优先展示网络状态、延迟、路由和潜在风险

## 运行方式

### 直接打开

可直接打开项目中的 `index.html` 文件：

```bash
open index.html
```

如果你在终端中使用 Linux，可以这样打开：

```bash
xdg-open index.html
```

### 本地服务器方式

推荐使用本地 HTTP 服务，避免某些浏览器限制：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 隐私说明

本项目的设计目标是“浏览器本地检测”，核心原则是：

- 不上传检测数据
- 不要求登录
- 不依赖后台存储
- 仅在本地浏览器环境中展示结果

但需要注意：

- 页面中的部分网络探测仍可能访问第三方资源（例如 IP 查询、站点探测地址）
- 检测结果仅用于网络诊断参考，不代表官方结论
- 站点可达性与业务可用性是两个不同维度，页面不保证目标服务本身可正常使用
