# NBAI · IP 与网络分流诊断

一个纯前端、浏览器本地运行的网络诊断工具，用于快速检查当前网络环境的出口 IP、分流策略、网站连通性、WebRTC 泄露情况以及终端环境信息。

线上地址：https://ip.nbai.dev

## 项目简介

NBAI 是一个轻量、可直接打开的网络观测页面，核心目标是：

- 检测本机的 IPv4 / IPv6 出口
- 对比国内与海外分流链路
- 评估常见国内 / 国际网站的连通性与延迟
- 检查 WebRTC 是否泄露本地或公网地址
- 识别 Anycast / Cloudflare 边缘节点命中情况
- 评估浏览器环境与隐私风险
- 所有检测逻辑在浏览器本地执行，不上传数据、不要求登录

它适合用于：

- 排查网络出口是否被绕过或被代理
- 检查国内与国际访问表现差异
- 验证 WebRTC / DNS / 浏览器环境是否存在隐私风险
- 直接在浏览器中快速进行网络诊断
- 复制诊断摘要、导出结果、保存检测历史

## 功能特性

### 1. IP 出口与分流检测
- 并发检测多路出口 IP
- 区分国内直连 / 国内 BGP / Anycast / 海外分流
- 识别浏览器可见的出口地址
- 支持隐藏 IP 用于截图和分享

### 2. 国内外站点连通性测试
- 监测国内热门站点（百度、B站等）
- 监测国际站点 / AI 平台（GitHub、YouTube 等）
- 自动统计连接成功率和平均延迟
- 支持重试与失败原因分类
- 支持站点探测结果筛选

### 3. WebRTC / 环境诊断
- 检查公网反射地址与局域网候选地址
- 评估是否存在 WebRTC 泄露
- 展示终端环境信息（浏览器、平台、UA、语言等）
- 提供风险等级评估与诊断结论

### 4. 自定义测速
- 可直接输入任意域名或 URL 进行即时连通性测速
- 适用于快速检验某个站点是否可访问

### 5. 结果导出 / 复制 / 分享
- 一键复制诊断摘要
- 导出 JSON / Markdown 报告
- 本地保存最近检测记录
- 支持浏览器的分享能力
- 适合截图、文档记录和复盘

## 设计原则

- 纯前端实现：本项目为静态 HTML/CSS/JS 页面
- 浏览器本地执行：数据不离开用户设备
- 无登录要求：不使用账号体系，也不依赖后端服务
- 强调可诊断性：页面尽可能展示各类网络状态与失败原因
- 结果可信、可解释：失败项必须能说明失败原因，而非简单“失败”

## 运行方式

### 直接打开
可以直接在浏览器中打开 `index.html`：

```bash
open index.html
```

或者使用本地静态服务器：

```bash
python3 -m http.server 8000
```

随后访问：

```text
http://localhost:8000
```

## 隐私说明

本项目在用户浏览器中完成检测，且不会主动上传检测内容到服务端。页面中所展示的 IP、网络状态、站点连通情况仅用于本地诊断和手动分享。

不过请注意：

- 部分第三方资源（如 IP 查询或站点探测地址）仍可能在浏览器中发起请求
- 该页面用于网络观测，不保证任何被测站点都具备业务可用性
- 结果仅供参考，不等同于运营商、代理或服务商的官方结论
- 浏览器隐私模式、CORS 策略和网络限制可能会影响部分探测结果

## 适用场景

- 验证当前网络是否正常分流
- 检查国内访问与国际访问的实际表现
- 判断是否存在 WebRTC 或代理相关隐私泄漏
- 记录网络环境的截图、诊断摘要或问题复现信息
- 对比同一网络环境下的历史检测变化
